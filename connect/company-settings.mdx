# Company settings

Company settings live on Profile under **About Company**. Editing is limited to roles with company edit permission (typically **Admin** and **Manager**).

**Path:** `/profile`

## View and edit company details

1. Open **Profile**.
2. Review **About Company** (company name, **Company ID**, address fields).
3. Copy **API Key** when you need credentials for API or automation work (treat as a secret).
4. If you have edit permission, update allowed fields and select **Save Changes**.
5. Use **Manage members** to invite company users — [Users and roles](/connect/users-and-roles).

Initial BigChange onboarding: [Company and BigChange setup](/connect/company-setup).

<Warning>
Never paste live API keys into public tickets, chat logs, or documentation screenshots.
</Warning>

# Notifications

Notifications are the alert rail for your user — Case updates, agent activity, and system messages. Open the linked record, then mark read or clear so the list stays useful.

**Path:** `/notifications`

## Review notifications

1. Open **Notifications** in the sidebar.
2. Use **Unread** (badge), **Read**, or **Cleared**.
3. Open a notification to land on the Case, job, or other linked work when a link is present.
4. Per row: **Read** or **Clear**. Bulk: **Read all**, **Clear all**.
5. Filter by **Agents**, **Users**, or **System** when you need to separate Connie/automation noise from people.

Treat unread Case and agent alerts as work to triage — not a feed to skim and ignore.

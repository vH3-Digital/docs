# Knowledge base

The knowledge base holds the documents your operation actually uses — SOPs, method statements, commercial packs. Upload them once, share them, and ask Tia instead of hunting the shared drive.

**Path:** `/knowledge`

## Browse and upload

1. Open **Knowledge base** in the sidebar.
2. Choose **My Documents** for personal drafts, or **Shared Documents** for company-wide material.
3. Select **Upload Document**.
4. Open a document at `/knowledge/:documentId`.
5. Use **Share this document** when it should appear under Shared Documents.

Keep shared SOPs in **Shared Documents** so coordinators and Connie-adjacent workflows can find the same source.

## Ask Tia

On a document, open **Ask Tia** to chat in document context — for example, what the SOP says before you update a Case comment or brief an engineer. Tia is contextual to knowledge, not a separate sidebar app. See [AI assistants](/connect/ai-assistants).

For company-wide operational questions, use [Ask Connie](/connect/ask-connie).

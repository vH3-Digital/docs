# Knowledge base

The knowledge base holds company documents for operators and assistants.

**Path:** `/knowledge`

## Prerequisites

- Signed-in user.

## Browse and upload

1. Open **Knowledge base** in the sidebar.
2. Choose **My Documents** or **Shared Documents**.
3. Select **Upload Document** to add a file.
4. Open a document to preview it at `/knowledge/:documentId`.
5. Use **Share this document** when you want it available under Shared Documents.

## Work with Tia

On a document, open **Ask Tia** (agent button) to chat in document context. Tia is contextual to knowledge — not a separate sidebar app. See [AI assistants](/connect/ai-assistants).

# App overview

VH3 Connect uses a left sidebar for primary areas, a header for search and Connie, and Profile for account admin.

**URL:** [https://app.vh3.ai](https://app.vh3.ai)

On desktop the sidebar starts as an icon rail. Hover or pin it to expand the labels.

## Sidebar

| Area | Path | Purpose |
|---|---|---|
| Dashboard | `/` | **Stats** and **Recent Activity** tabs |
| Activity | `/activity` | The work VH3 AI is doing for your company, live |
| Jobs | `/jobs` | Active, Planned, Overview (+ job detail drawer) |
| Knowledge base | `/knowledge` | Library documents, upload, Tia |
| Prompts | `/prompts` | Your own, your team's and VH3 AI's prompts for Connie, Tia and Salma |
| Sales performance | `/sales` | Quotient quotes |
| Quote Documents | `/quoting/documents` | VH3 follow-on drafts — letter, lines, costs, price, approval check, Salma |
| Contacts | `/contacts` | Directory and contact drawer (Connie) |
| Cases | `/cases` | My Cases / All Cases — status, evidence, Assigned Team |
| Sentinels | `/sentinels` | Sentinel alerts and opportunities, coverage and settings |
| Portal Jobs | `/portal-jobs` | Ingest review — Awaiting evaluation, Correct, Incorrect |
| Teams | `/teams` | Ownership groups for Cases and portfolios |
| Notifications | `/notifications` | Unread, Read, Cleared |
| Integrations | `/integrations` | Connected / available systems, CSV upload |
| Worksheet Pass | `/settings/worksheet-pass` | How engineers' free-text worksheet answers are tidied or rewritten (admins only) |

**Prompts** and **Sentinels** are switched on per company, so they may be missing from your sidebar.

Company users and invites live under Profile → [Users and roles](/connect/users-and-roles).

## Header

- **Search** — global overlay with jobs, contacts, Library **Documents** and a parts preview; **Advanced search** at `/search` (Create case, Ask Connie).
- **Ask Connie** — global Connie drawer on every signed-in screen, including hands-free calls.

## Profile

Open **Profile** (`/profile`) for **User Profile**, **Passkeys**, **About Company** (API Key), **Manage users**, **Subscription**, and **Invoices** (role-gated). The user menu sits on the sidebar rail.

## Available today

- Sign-in with a password or a passkey, invite/join, register, verify, company create, BigChange setup
- Dashboard **Stats**
- Activity: the live queue, lanes, finished work and the log
- Jobs Active / Planned / Overview and job detail tabs
- Knowledge base upload, share, Google Drive import and Tia, with page citations in Connie's answers
- Prompts in every assistant chat, and the Prompts page
- Quote Documents: lines, costs and margin, price, versions, comments, activity, approval check, Client PO and Ask Salma
- Sales performance Quotes (Quotient)
- Contacts + Connie
- Cases: My Cases / All Cases, Create case on the list, Assigned Team, participants, comments, and activity
- Sentinels: Overview, Alerts, Opportunities, Coverage and settings
- Portal Jobs: Awaiting evaluation / Correct / Incorrect, mark a match, overview scores
- Teams as a sidebar area (`/teams`) and as Assigned Team on a Case
- Global and advanced search, including Library documents and a parts preview in header search
- Notifications with Read/Clear and filters
- Integrations portal + CSV **Upload file**
- Profile: Manage users with invites, resend and revoke, and the company API key
- Hands-free calls with Connie, Tia and Salma

## Not in the app yet

- Workflow Builder — in development; it is not in the sidebar today
- Dedicated engineers / vehicles / resources pages
- Jobs **Stats** tab and Sales **Report** tab (present but disabled)
- Some header-search filters that are not backed yet

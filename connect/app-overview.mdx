# App overview

VH3 Connect uses a left sidebar for primary areas, a header for search and Connie, and Profile for account admin.

**URL:** [https://app.vh3.ai](https://app.vh3.ai)

## Sidebar

| Area | Path | Purpose |
|---|---|---|
| Dashboard | `/` | Stats and activity tabs |
| Jobs | `/jobs` | Active, Planned, Overview (+ job detail drawer) |
| Knowledge base | `/knowledge` | Documents, upload, Tia |
| Sales performance | `/sales` | Quotes and Salma |
| Contacts | `/contacts` | Directory and contact drawer (Connie) |
| Cases | `/cases` | Cases with scope and status filters |
| Notifications | `/notifications` | Unread, Read, Cleared |
| Integrations | `/integrations` | Connected / available systems, CSV upload |

## Header

- **Search** — global search overlay; **Advanced search** at `/search` (Create case, Ask Connie).
- **Ask Connie** — global Connie drawer on every signed-in screen.

## Profile

Open **Profile** (`/profile`) for **User Profile**, **About Company** (including API Key and Manage members), **Subscription**, and **Invoices** (role-gated).

## Available today

These flows work end-to-end in the product:

- Sign-in (**Continue**, Remember me, Forgot password), invite/join, register, verify, company create, BigChange setup
- Dashboard **Stats** (prefer this over **Recent Activity** until the activity feed is fully live)
- Jobs Active / Planned / Overview and job detail tabs
- Knowledge upload/share + Tia; Sales Quotes + Salma; Contacts + Connie
- Cases with scope/status filters and detail tabs
- Global and advanced search for supported types; Create case / Ask Connie from a selection
- Notifications with Read/Clear and filters
- Integrations portal + CSV **Upload file**
- Profile team invite (Admin/Manager) and company API key

## Not in the app yet

These are not customer-facing Connect surfaces today:

- Workflow Builder
- Dedicated engineers / vehicles / resources pages
- Jobs **Stats** tab and Sales **Report** tab (present but disabled)
- Some header-search filters that are not backed yet
- Voice / communication hub as a first-class nav area

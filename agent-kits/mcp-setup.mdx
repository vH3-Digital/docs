# MCP Server

VH3 AI is an MCP connector in Claude and ChatGPT. You sign in on VH3's hosted page with the email and password you use for VH3 Connect. Same sign-in, same company data: jobs, invoice and quote totals, scheduling suggestions, worksheets and photos. You only ever see your own company's data.

Use **hosted MCP OAuth**. There is nothing to install and no local key file. Developers who connect Cursor, Claude Code, n8n or a custom agent can use a token under [Advanced: developer access](#advanced-developer-access). Most Claude and ChatGPT users should use hosted OAuth.

<Note>
If you still have the old Claude developer test connector, delete it before you add this one: **Settings → Developer → Delete VH3**.
</Note>

## Connect in Claude

This works on claude.ai, Claude Desktop, Claude mobile and Cowork. Your plan needs to allow custom connectors. On Team and Enterprise plans, an owner adds the connector once for the organisation.

<Steps>

    Open Claude, then **Customize** or **Settings → Connectors → Add custom connector**.
  </Step>
  <Step title="Enter the VH3 AI details">
    Name it `VH3 AI`. Server URL:

    ```text
    https://mcp.vh3.ai/mcp
    ```

    Use that URL exactly, with no trailing slash and no path after `mcp`.
  </Step>
  <Step title="Leave the defaults, then Add and Connect">
    Leave the defaults. The OAuth client stays on **Use Claude's published identity**. Transport stays on **Streamable HTTP**. Click **Add**, then **Connect**.

  <Step title="Sign in with your VH3 email and password, then Allow">
    A VH3 page opens. Sign in with your VH3 Connect email and password. Your password goes to VH3 only.

    On Claude Desktop, the browser may ask you to finish connecting. Choose **Continue connecting** only if you started this from Claude. A link on its own does not connect anything to your account.

    <Frame caption="Claude Desktop asks you to finish connecting. Choose Continue connecting.">
      <img
        src="/images/mcp/claude-finish-connecting.png"
        alt="Finish connecting a connector page with a Continue connecting button"
      />
    </Frame>

  <Step title="Wait for the tools and set permissions">
    Wait a few moments for the connector tools to load, then set permissions. Read tools can stay on. You can disconnect VH3 AI in Claude's connector settings at any time. To change the Allow actions choice, disconnect and connect again.

  </Step>
</Steps>

### Sign in with your VH3 account

The hosted page asks for the email and password you use for VH3 Connect.

If sign-in fails, check the message on the page:

| Message | What to do |
|---|---|
| That email or password is not right | Check both and try again. Reset your password from the VH3 Connect login page if needed. |
| Too many attempts | Wait a few minutes, then try again. |
| This VH3 account is no longer active | Contact your VH3 administrator. |
| Your company has not finished setting up VH3 AI access | Ask your VH3 administrator to enable it. |
| VH3 sign-in is not available right now | Try again shortly. |

### Choose what Claude may do

After sign-in, the page asks what to allow.

- **Read access** is always granted. Claude can read jobs, engineers, sites, customers, quotes, invoices and reports for your company, and runs these tools without asking each time.
- **Allow actions** appears only when VH3 AI offers a tool that can act for you, such as **Ask Connie**, which can send email and SMS, create drafts and queue quotes. It is unticked by default. Tick it only if you want those actions. Each action asks you to confirm first.

Choose **Allow** to finish. See the [privacy policy](https://www.vh3.ai/legal-and-compliance/privacy-policy) and [terms](https://www.vh3.ai/legal-and-compliance/vh3-ai-product-terms-and-conditions) for how VH3 handles your data.

### Try it

Ask Claude:

- *"How many jobs did we complete last week, broken down by engineer?"*
- *"Which sites have had repeat visits this month?"*
- *"Who could take job 12345 this week?"*

Claude calls **Job metrics** for the first question and shows a chart in the chat. For the third, it calls **Who could take a job, and when** and lists engineers with times.

### What you'll see in Claude

In claude.ai and Claude Desktop, many answers open as a card you can use in the chat. Claude Code shows the same answers as text.

| Ask about | Card |
|---|---|
| Counts, rates and trends | A chart. Switch the measure or the grouping, and compare two periods |
| Who could take a job | A picker of engineers and start times. Each slot is an offer; a person books it on the schedule |
| One job | A job card with status, customer and site, engineer, planned against actual times, and the VH3 summary |
| One invoice or quote | The status, dates, line items, VAT and totals |
| A list of invoices or quotes | A sortable table with a status filter and totals for each currency |
| One customer or site | Details, job totals, recent jobs and the VH3 customer summary |

<Note>
**Claude Code** can use the same hosted server. Run `claude mcp add --transport http vh3-ai https://mcp.vh3.ai/mcp`, then sign in when Claude asks. The Bearer token and local JSON config are under [Advanced: developer access](#advanced-developer-access).
</Note>

## Connect in ChatGPT

Leave the OAuth settings as ChatGPT fills them in. Tick the custom plugin risk acknowledgement when it appears.

<Steps>
  <Step title="Open Add custom MCP server">
    Go to [chatgpt.com](https://chatgpt.com) → **Plugins** (left menu) → **Add** (top right) → **Add custom MCP server**.
  </Step>
  <Step title="Enter the VH3 AI details">
    Fill in:

    - **Name:** VH3 AI
    - **Description:** Connects to the Job and field service operations
    - **Connection:** Server URL
    - **URL:** `https://mcp.vh3.ai/mcp`
    - **Authentication:** OAuth
  </Step>
  <Step title="Leave the Advanced OAuth defaults">
    Open **Advanced OAuth settings** and confirm the hosted defaults below.

    - **Registration method:** Client Identifier Metadata Document (CIMD)
    - Leave the Callback URL, the CIMD client metadata URL, and the default scopes unchanged
  </Step>
  <Step title="Create the plugin">
    Tick **I understand and want to continue**, then click **Create as a plugin**.
  </Step>
  <Step title="Connect your VH3 account">
    Find **VH3 AI** in installed plugins → **Connect** → **Continue to VH3 AI**. Sign in with your VH3 Connect email and password, then **Approve**.
  </Step>
  <Step title="Test the connection">
    Open a new chat and ask:

    ```text
    Using VH3 AI, show me the latest five jobs and their current status.
    ```

    If ChatGPT retrieves the jobs, the connection is working.
  </Step>
</Steps>

## Available tools
Once connected, Claude and ChatGPT can use these tools. They need no `company_id` or `api_key`, because your sign-in identifies your company.

### Jobs and sites

| Tool | What it does |
|---|---|
| **List jobs** (`list_jobs`) | Lists jobs with filters for status, type, customer and engineer. Filter by the date a job was created, or by the day it is planned |
| **Get job** (`get_job`) | Returns one job with worksheets and site history. Shows a job card in the chat |
| **Job metrics** (`aggregate_jobs`) | Counts, rates, rankings and trends for a period, with comparison and grouping. Shows a chart in the chat |
| **Investigate an operational question** (`investigate`) | Finds the cause behind a pattern, using evidence from your jobs |
| **Search past job outcomes** (`search_outcomes`) | Finds similar faults and what happened last time |
| **Weather for a job** (`weather_for_job`) | Shows the weather at a job's site and time |
| **Run sentinel checks** (`run_sentinels`) | Runs your early-warning checks on demand |

### Customers, engineers and search

| Tool | What it does |
|---|---|
| **Search customers, engineers, jobs and sites** (`search_autocomplete`) | Finds records by name, postcode or reference |
| **List contacts** (`contacts_feed`) | Lists customers with free-text search |
| **Get contact** (`contact_detail`) | Returns one customer with history. Shows a customer card in the chat |
| **Engineer skills** (`resource_skills`) | Lists the skills held by one engineer |
| **List resource groups** (`list_resource_groups`) | Lists your engineer and vehicle groups |
| **Who could take a job, and when** (`scheduling_suggestions`) | Offers engineers and times for a job, ranked by VH3. Shows a picker in the chat. It suggests; a person books on the schedule |
| **Company and platform status** (`company_snapshot`) | Shows your company profile and platform health |

### Quotes and invoices

| Tool | What it does |
|---|---|
| **List BigChange quotes** (`list_quotes`) | Lists quotes with filters. Shows a sortable table in the chat |
| **Get BigChange quote** (`get_quote`) | Returns one quote with line items. Shows a quote card in the chat |
| **List Quotient quotes** (`list_quotient_quotes`) | Lists Quotient quotations, for companies that use Quotient |
| **Get Quotient quote** (`get_quotient_quote`) | Returns one Quotient quotation with line items |
| **Quote totals and conversion** (`quote_summary`) | Exact quote totals and conversion for a period |
| **List invoices** (`list_invoices`) | Lists invoices with filters. Shows a sortable table in the chat |
| **Get invoice** (`get_invoice`) | Returns one invoice with line items and payment status. Shows an invoice card in the chat |
| **Invoice totals** (`invoice_summary`) | Exact invoice totals and outstanding amounts for a period |

<Note>
Reports and **Ask Connie** are switching on in stages. **Generate operational report** (`reports_generate`) and **Ask Connie (can take actions)** (`connie_chat`) appear in the list when they are live for your company. Connie through this connector sends email, SMS and notifications. It does not place voice calls.
</Note>

<Warning>
`investigate`, the totals tools and `scheduling_suggestions` can take a while on large periods. If Claude reports that a call took too long, narrow the period or the question and ask again.
</Warning>

## Troubleshooting a Claude connection

### "Add custom connector" is missing

Your plan or organisation settings may not allow custom connectors. On Team and Enterprise plans, ask an owner to add the connector in **Organization settings → Connectors**.

### Sign-in opens, but Claude shows an error afterwards

Disconnect VH3 AI in Claude's connector settings and connect again. The connector URL is exactly `https://mcp.vh3.ai/mcp`, with no trailing slash and no path after `mcp`.

### VH3 tools disappear after working for a while

Your VH3 account may have been archived, or your sign-in expired after a long period of no use. Connect again. If sign-in then fails with a message, see the table above.

### Connie is missing from the tool list

Disconnect and connect again, and tick **Allow actions** on the consent page. Connie also appears only once it is live for your company.

### Your organisation blocks the connection

Ask your IT team to allow outbound HTTPS to `mcp.vh3.ai`.

### ChatGPT does not finish connecting

Check the server URL is exactly `https://mcp.vh3.ai/mcp`. Authentication stays **OAuth**. Registration method stays **Client Identifier Metadata Document (CIMD)**. Leave the callback URL, the CIMD client metadata URL, and the scopes unchanged, and tick **I understand and want to continue** before **Create as a plugin**. Then use **Connect → Continue to VH3 AI** and sign in with your VH3 Connect email and password.

## Advanced: developer access

Developers can connect Cursor, Claude Code, n8n and custom agents directly with a Bearer token. This path needs no OAuth sign-in. It talks to the VH3 MCP server at `api.vh3connect.io`, and it works for tools such as Claude Desktop that read a local config file.

<Note>
Most Claude and ChatGPT users should use hosted OAuth: [Connect in Claude](#connect-in-claude) or [Connect in ChatGPT](#connect-in-chatgpt). This section is for developers. The direct server also lists `jobs_feed` (an alias for `list_jobs`), and it lists `reports_generate` and `connie_chat` ahead of the connector.
</Note>

### Server details

| Property | Value |
|---|---|
| **Server URL** | `https://api.vh3connect.io/x2/mcp/UZkEeuG7/mcp/stream` |
| **Transport** | Streamable HTTP via `mcp-remote` proxy |
| **Auth** | Bearer JWT token in `Authorization` header (obtained from `auth/mcp-token`) |
| **Protocol version** | MCP 2025-06-18 |

<Note>
If an existing client config still uses a URL ending `/mcp/sse`, change it to `/mcp/stream` and fully restart the client. Your JWT is unchanged.
</Note>

### Prerequisites

Claude Desktop and Cursor connect to remote MCP servers via a lightweight proxy called [`mcp-remote`](https://www.npmjs.com/package/mcp-remote). It runs automatically through `npx`, which ships with Node.js.

<Steps>
  <Step title="Install Node.js (if not already installed)">
    Download the **LTS** installer for your platform from [nodejs.org](https://nodejs.org/en/download):

    - **macOS:** Download the `.pkg` installer from [nodejs.org](https://nodejs.org/en/download), open it, and click through the wizard. No terminal required.
    - **Windows:** Download the `.msi` installer. Make sure **"Add to PATH"** is checked during installation (this is the default).

    After installing, verify by opening a terminal (macOS: Terminal.app, Windows: Command Prompt) and running:

    ```bash
    node --version
    npx --version
    ```

    Both should return a version number (e.g. `v22.x.x`). If `npx` is not recognised, Node.js is either not installed or not in your system PATH — see [Troubleshooting developer access](#troubleshooting-developer-access) below.
  </Step>
  <Step title="Confirm your IT policy allows outbound HTTPS">
    The MCP proxy makes outbound HTTPS connections to `api.vh3connect.io` and `registry.npmjs.org` (to fetch `mcp-remote` on first use). If your organisation uses a firewall or proxy, ask your IT team to allowlist these domains.
  </Step>
</Steps>

<Info>
**Why Node.js?** Claude Desktop's config file launches local (stdio) MCP processes. The [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) proxy runs locally and opens the HTTPS connection to VH3. This is [the standard pattern](https://modelcontextprotocol.io/quickstart/user) recommended by the MCP specification.
</Info>

### Get your MCP token

Before connecting any client, you need a long-lived MCP token (valid for 90 days).

<Steps>
  <Step title="Log in to get a session JWT">
    Call the login endpoint with your email and password to obtain a standard session token:

    ```bash
    curl -X POST https://api.vh3connect.io/api:lBQnyyZL/auth/login \
      -H "Content-Type: application/json" \
      -d '{"email": "you@company.com", "password": "your-password"}'
    ```

    Copy the `authToken` from the response.
  </Step>
  <Step title="Exchange it for an MCP token">
    Call the `auth/mcp-token` endpoint using your session token:

    ```bash
    curl -X POST https://api.vh3connect.io/api:lBQnyyZL/auth/mcp-token \
      -H "Authorization: Bearer YOUR_SESSION_TOKEN"
    ```

    The response contains `authToken` (your 90-day MCP token) and `expires_in: 7776000`.
  </Step>
  <Step title="Store the token securely">
    Save the MCP token in an environment variable. Never commit it to source control.

    ```bash
    export VH3_MCP_TOKEN="eyJhbGci..."
    ```
  </Step>
</Steps>

### Quick start: Claude Desktop

Claude Desktop connects to the VH3 MCP server using the [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) proxy. Requires [Node.js 18+](#prerequisites).

<Steps>
  <Step title="Open your Claude Desktop config file">
    The config file location depends on your platform:

    | Platform | Path |
    |---|---|
    | **macOS** | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | **Windows** | `%APPDATA%\Claude\claude_desktop_config.json` |

    You can also open it from Claude Desktop: **Settings → Developer → Edit Config**.

    Create the file if it does not exist.
  </Step>
  <Step title="Add the VH3 server">
    **macOS:**

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "vh3-ai": {
          "command": "npx",
          "args": [
            "-y",
            "mcp-remote",
            "https://api.vh3connect.io/x2/mcp/UZkEeuG7/mcp/stream",
            "--header",
            "Authorization:${VH3_MCP_TOKEN}"
          ],
          "env": {
            "VH3_MCP_TOKEN": "Bearer YOUR_MCP_TOKEN"
          }
        }
      }
    }
    ```

    **Windows:**

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "vh3-ai": {
          "command": "cmd",
          "args": [
            "/c",
            "npx",
            "-y",
            "mcp-remote",
            "https://api.vh3connect.io/x2/mcp/UZkEeuG7/mcp/stream",
            "--header",
            "Authorization:${VH3_MCP_TOKEN}"
          ],
          "env": {
            "VH3_MCP_TOKEN": "Bearer YOUR_MCP_TOKEN"
          }
        }
      }
    }
    ```

    Replace `YOUR_MCP_TOKEN` with the token from [Get your MCP token](#get-your-mcp-token).
  </Step>
  <Step title="Restart Claude Desktop">
    Quit fully (**Cmd+Q** on macOS, **File → Quit** on Windows — closing the window is not enough) and reopen. You should see a hammer icon in the chat input. Click it to confirm the VH3 tools are listed.
  </Step>
  <Step title="Test with a query">
    Try: *"How many jobs did we complete last week, broken down by engineer?"*

    Claude will call `aggregate_jobs` and return a cited answer.
  </Step>
</Steps>

<Warning>
**Windows users:** You must use `"command": "cmd"` with `"/c"` as the first arg. Claude Desktop spawns the command directly without a shell, so `npx` alone will fail with `spawn npx ENOENT`. Wrapping it in `cmd /c` ensures Windows resolves `npx` via the system PATH.
</Warning>

<Note>
The auth token is placed in the `env` block rather than inline in `args`. This is the [recommended pattern](https://www.npmjs.com/package/mcp-remote) — `mcp-remote` can misparse header values containing spaces when they appear directly in the args array on Windows.
</Note>

### Authentication

The MCP server uses JWT Bearer token authentication. Tokens are obtained via the `auth/mcp-token` endpoint (see [Get your MCP token](#get-your-mcp-token) above).

| Property | Value |
|---|---|
| **Header** | `Authorization: Bearer <token>` |
| **Token lifetime** | 90 days |
| **Scope** | Automatically resolves your user, company, and API credentials |

The JWT encodes your user identity. All tool calls are automatically scoped to your company, no `company_id` or `api_key` parameters are needed. Cross-tenant access is impossible.

<Warning>
Never commit your MCP token to source control. Use environment variables and reference them from your MCP client configuration.
</Warning>

### Troubleshooting developer access

#### `spawn npx ENOENT` (Windows)

Claude Desktop cannot find `npx`. Two possible causes:

1. **Node.js is not installed.** Install it from [nodejs.org](https://nodejs.org/en/download) and restart Claude Desktop.
2. **Node.js is installed but not in Claude Desktop's PATH.** Use `"command": "cmd"` with `"/c"` as the first arg (see [Windows config above](#quick-start-claude-desktop)). Alternatively, use the full path to npx: `"command": "C:\\Program Files\\nodejs\\npx.cmd"`.

#### `npx is not recognized` (Windows)

Same root cause as above — Node.js is not on the system PATH. Install Node.js using the `.msi` installer (not the zip), which adds it to PATH automatically. After installing, **restart Claude Desktop** (or reboot) so it picks up the new PATH.

#### "Not valid MCP server configuration"

The config JSON is malformed. Common causes:

- **Trailing comma** after the last entry in an object or array.
- **Two separate JSON objects** instead of one (e.g. `mcpServers` and `preferences` in separate `{}` blocks — they must be siblings in a single root object).
- **Using `"url"` or `"headers"` keys** — Claude Desktop does not support these. Use the `command` + `mcp-remote` pattern shown above.

Paste your config into [jsonlint.com](https://jsonlint.com) to validate the JSON syntax.

#### Tools don't appear after restart

- Verify you fully quit Claude Desktop (**Cmd+Q** / **File → Quit**), not just closed the window.
- Check logs: **Settings → Developer → Open Logs Folder** and look for `mcp-remote` stderr output.
- Verify your token hasn't expired (90-day lifetime). Re-run the [token exchange](#get-your-mcp-token) if needed.
- Confirm outbound HTTPS to `api.vh3connect.io` and `registry.npmjs.org` is not blocked by a firewall.
- Confirm the server URL ends `/mcp/stream`, not `/mcp/sse`.

#### Tool calls timeout

`investigate`, `reports_generate`, and `connie_chat` can take 10–17 seconds. Some clients have aggressive timeouts. Increase your client's tool call timeout to at least 25 seconds. `scheduling_suggestions` can take up to 45 seconds, and a live `invoice_summary` or `quote_summary` up to 90 seconds.

### Using the MCP server from custom agents

For agents built with the Anthropic SDK, OpenAI Agents SDK, or similar frameworks:

<CodeGroup>

```python Python (Anthropic SDK)
import os
import anthropic

client = anthropic.Anthropic()

response = client.beta.messages.create(
    model="claude-opus-4-5",
    max_tokens=4096,
    mcp_servers=[
        {
            "type": "url",
            "url": "https://api.vh3connect.io/x2/mcp/UZkEeuG7/mcp/stream",
            "name": "vh3-ai-v2",
            "authorization_token": os.environ["VH3_MCP_TOKEN"],
        }
    ],
    messages=[{"role": "user", "content": "What needs attention today?"}],
)
```

### Tool selection guide for agents

When your agent receives a free-form question and needs to decide which tool to call:

| Question pattern | Tool |
|---|---|
| "why / root cause / what's causing / investigate" | `investigate` |
| "how many / rate / trend / top / compare / period over period" | `aggregate_jobs` |
| "who could take this Job / when could we send someone" | `scheduling_suggestions` |
| "how much / how many invoices" | `invoice_summary` |
| "how many quotes / conversion" | `quote_summary` |
| "which group / resource group name" | `list_resource_groups` |
| "show me / list / find / get jobs" | `list_jobs` or `jobs_feed` |
| "what needs attention / alerts / sentinels" | `run_sentinels` |
| "generate report / briefing / debrief / weekly summary" | `reports_generate` |
| "similar to / fault like / what else looks like" | `search_outcomes` |
| "find customer / contact / site" | `contacts_feed` or `search_autocomplete` |
| "quotes / pricing / quotations" | `list_quotes` or `get_quote` |
| "invoices / billing / payments" | `list_invoices` or `get_invoice` |
| Ambiguous / unclear | `aggregate_jobs` first, then offer `investigate` |

For a full system prompt you can paste directly into your agent, see the [Claude.ai Projects](/agent-kits/claude-projects) and [n8n Agent Prompts](/agent-kits/n8n-agents) kits, both include routing logic optimised for agent use.
